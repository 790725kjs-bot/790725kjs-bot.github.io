Privacy Policy — 오늘 하나만 채널 관리 도구 · 시행일 2026년 10월 3일

「오늘 하나만 채널 관리 도구」(이하 '이 도구')는 유튜브 채널 「오늘 하나만」의 운영자가 자기 채널을 관리하기 위해 개인 PC에서 사용하는 프로그램입니다. 일반 사용자에게 제공하는 서비스가 아니며, 운영자 본인 외의 개인정보를 수집하지 않습니다.

1. 접근하는 정보

이 도구는 구글 로그인(OAuth)을 통해 운영자 본인의 유튜브 채널에 대해 아래 정보를 읽기 전용으로 가져옵니다.

  • 채널의 영상 목록, 제목, 공개 상태, 예약 게시 시각 (YouTube Data API · youtube.readonly)
  • 채널의 조회수, 시청 시간, 시청 지속률, 유입 경로, 시청자 연령대·성별 통계 (YouTube Analytics API · yt-analytics.readonly)

통계는 유튜브가 제공하는 집계 수치이며, 개별 시청자를 식별할 수 있는 정보는 포함되지 않습니다.

2. 이용 목적

  • 예약한 영상이 정해진 시각에 게시되는지 확인
  • 영상별 성과를 살펴 다음 영상의 주제와 구성을 정하는 데 참고

3. 보관과 삭제

가져온 정보와 인증 정보는 운영자의 개인 PC에만 저장됩니다. 외부 서버로 전송하거나 따로 보관하지 않습니다. 운영자가 PC에서 해당 파일을 지우면 즉시 삭제됩니다.

4. 제3자 제공

가져온 정보를 제3자에게 제공·판매·공유하지 않습니다. 광고 목적으로 사용하지 않습니다.

5. Google API 서비스 이용

이 도구가 Google API로 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요건 포함)을 따릅니다. 이 도구는 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

6. 접근 권한 철회

운영자는 언제든지 구글 계정의 보안 설정에서 이 도구의 접근 권한을 취소할 수 있습니다.

7. 문의
